# ДОЖИМ

Сатирический лендинг вымышленного стартапа: браслет, который бьёт током за
неполное использование оплаченного AI-лимита. Версия для юрлиц — ошейник
УТИЛИЗАТОР. Страница оформлена как эфир телемагазина со сбором средств.

## Запуск

```bash
python3 -m http.server 8777    # затем http://127.0.0.1:8777
```

Статика без сборки: `index.html`, `styles.css`, `app.js`, `assets/*.webp`.
GSAP + ScrollTrigger и шрифты (Unbounded, Golos Text) подтягиваются с CDN.

## Что где

- `index.html` — вся разметка и тексты.
- `styles.css` — токены палитры и типографики в `:root`, дальше секции по порядку страницы.
- `app.js` — часы эфира, тающий остаток партии, интро и четыре скролл-триггера.
  При `prefers-reduced-motion` анимации не создаются; конечные состояния лежат
  в разметке, поэтому страница корректна и без JS.
- `assets/` — рендеры товаров и кадры «до/после», сгенерированы нейросетью.
